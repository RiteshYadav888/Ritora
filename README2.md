# 📚 Ritora — AI Study Planner

> Plan smarter. Study better. Achieve more.

Ritora is a modern study planner web application designed to help students organize their study tasks, manage priorities, track progress, and maintain focused study sessions.

## 🚀 Live Demo

👉 https://riteshyadav888.github.io/Ritora/

## ✨ Features

- 📊 Modern student dashboard
- 📝 Add, complete, and delete study tasks
- 🎯 Task priority management
- ⏱️ Study time tracking
- 📈 Weekly progress tracking
- 🤖 Rule-based study recommendations
- 💾 LocalStorage-based data persistence
- 🍅 Pomodoro study section
- 📱 Responsive design
- 🌙 Modern dark UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
